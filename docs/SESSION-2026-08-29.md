## Fleet deployment model (adopted 2026-08-29)

**One shared template repo, many env-configured Vercel projects.** A new clinic
is a new Vercel project importing `orilume-agent-core` — branding, credentials,
and knowledge all live in env vars; a push ships fleet-wide. A `stable` branch
exists for optional release pinning (promote `main` → `stable`). Forks are
reserved for clinics needing custom code. Orilume Dashboard's Setup Timeline
walks: Create the deployment → Clinic identity (incl.
`NEXT_PUBLIC_CLINIC_PHYSICIANS`) → Brand → Booking/EMR → Email → **Security &
retention (GENERATES per-clinic ADMIN_PASSWORD / ONBOARD_PASSWORD /
CRON_SECRET / KNOWLEDGE_KEY; maps RETENTION_DAYS + Upstash)** → Knowledge →
Validate → **Privacy go-live sign-off** (five steps from PRIVACY-HARDENING.md;
saved answers are the clinic's compliance record).
